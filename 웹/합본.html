1-1. 데이터 vs 정보, DIKW ★

단계 정의 예
Data 가공 전 사실 A대리점 100만, B 200만

  • 변화 ☞ 전후양상: 전수조사, 사후처리, 양, 상관관계

유형 키워드 예 함정

  • JSON ★: 자바스크립트 기반 키-값 쌍 텍스트
  • 정량(수치) vs 정성(언어·인터뷰 텍스트)
  • 내부 vs 외부, 가역 vs 불가역도 가끔

스키마 선정의, 엄격 (Schema-on-Write) 유연·스키마리스 파일 단위, 스키마 약함
일관성 ACID, 정규화 BASE, eventual 복제 3벌, 내결함
확장 수직 확장 중심 수평 확장 노드 추가 수평 확장
처리 트랜잭션·조인 단순 조회·대규모 배치, 높은 처리율
실시간 좋음 (OLTP) 유형에 따라 부적합 (파일 기반)
데이터 정형 반정형·비정형 강점 모든 원본 파일

함정 세트
- HDFS를 “낮은 응답 지연(실시간)”이라고 하면 오답. 설계 목적은 높은 처리율(throughput), 배치.
- NoSQL = “SQL을 안 쓴다”가 아니라 Not Only SQL (비관계형 + 수평확장).
- RDB만의 특징: 조인·정규화·강결합 스키마·트랜잭션.

1-4. ETL · ODS · DW · DM · Data Lake 특강 100%

OLTP(현업 운영) → ODS(운영 임시 통합) → ETL → DW(전사) → DM(부서) → OLAP/BI
                              ↘ Data Lake(원본 그대로, 하둡/S3)
용어 한 줄 특강 포인트
ETL Extract → Transform → Load 운영DB → DW. 추출·변환·적재 기능 정의
ODS Operational Data Store. 현업 운영 저장소의 통합 중간층 ADP와 동일 문항. 이번 회 예상
DW 전사 분석용. Inmon 4특징: 주제지향·통합·시계열·비휘발성 함정: ‘확장성’은 4특징 아님
DM 부서·주제별 소규모 DW DW의 부분집합
Data Lake 정형~비정형 원본 포맷 그대로 Schema-on-Read
DW 구조를 먼저 만들고 저장 Schema-on-Write
특강 강력 예상

Lake = 포맷을 정하지 않고 가져온다 (스키마 온 리드). DW = 포맷을 만들어 놓고 저장 (스키마 온 라이트).

OLTP vs OLAP
- OLTP = 거래 실시간 입력수정삭제 / OLAP = 다차원 대화식 분석
- OLAP 5연산: Roll-up, Drill-down, Slice, Dice, Pivot
- BI = 무슨 일이 있었나 / BA = 왜, 앞으로 어떻게
- 내부 DB 활용 예: ERP·CRM·SCM. 외부 SNS 분석은 내부 활용 아님 ★

HDFS 특강 100%

  • 구글 GFS를 모사한 클론. NameNode(마스터, 메타데이터) + DataNode(슬레이브, 블록 저장, 복제 기본 3)
  • 블록 크기 변경 가능. 대용량 특화 (소규모 파일에 부적합)
  • 낮은 지연 시간보다 높은 처리율. 실시간 X, 배치 O
  • 내결함성 = 일부 노드 죽어도 복제본으로 계속 동작

2-1b. 상관 특강 — 매회 1문항

상관 = 두 변수의 강도 + 방향. 다변량이지만 탐색에도 위치.

공분산 Cov 피어슨 r
범위 −∞ ~ +∞ −1~1
단위에 민감 표준화한 공분산

특강 포인트
- 독립 → Cov=0 (O) / Cov=0 → 독립 (X, 비선형 가능)
- 피어슨: 구간·비율, 선형, 이상치 민감
- 스피어만: 서열. 구간·비율을 순위화 가능. 비선형(단조)도 포착 ★ 전부 출제 포인트
- 상관 크기만으로 통계적 유의성 불가 → 가설검정 필요
- 켄달 τ도 순위 기반

3-3. 조건부 확률 · 베이즈

P(A|B)=P(A∩B)/P(B)
독립이면 P(A∩B)=P(A)P(B), P(A|B)=P(A) — 교집합 계산이 다름 특강
배반 ≠ 독립
베이즈: P(A|B)=P(B|A)P(A)/P(B) — 초기엔 많이, 최근 가중치↓. 유도 관계만.

3-5. 추정

불편추정량: 한 번 구한 표본평균이 모평균과 같다는 뜻이 아님.
표본평균의 기댓값이 모평균과 같을 때 = 불편. 특강 (오답 고르기용으로 정의를 정확히)

좋은 추정량 ☞ 불효일충: 불편, 효율(분산 작을수록, “분산 0”은 함정), 일치, 충족
표본분산 n−1: 불편추정
MSE = Var + Bias²

구간추정
- 점추정은 오류 큼 → 구간 + 반드시 신뢰수준 명시
- 95%의 의미: 같은 방법으로 100번 중 95번 모수를 포함. 확률이 아님 (모수는 상수)
- 신뢰수준↑ → 구간 넓어짐 / 표본 n↑ → 구간 좁아짐
- n을 4배로 → 구간 폭은 약 1/2 (√n)
- z: 90% 1.645 / 95% 1.96 / 99% 2.576
- 모분산 알면 z, 모르면 t(df=n−1)
- 계산은 과거 회차 선까지. 확장 금지 특강

3-6. 가설검정 특강 · 실기 3유형과 동일

  • 검정 대상은 귀무가설. 반박 근거 있으면 기각, 없으면 기각하지 못함 ≠ 귀무가 참
  • H0: 같다·차이없다 / H1: 입증할 주장
  • 단측: 크다·작다·증가·감소 / 양측: 같지 않다
  • α = 1종 허용 = P(참인 H0 기각)
  • β = 2종 = P(거짓 H0 채택)
  • 검정력 = 1−β
  • p < α → H0 기각
H0 참 H0 거짓

미기각 OK 2종 β

모수적 검정의 가정 1호 = 정규성. 확인: Shapiro, K-S, Q-Q, Jarque-Bera, 히스토그램
- t: 단일 / 대응(같은 대상 전후) / 독립 두 집단

5. SVM · KNN

SVM
- 선형·비선형 모두. 비선형 = 커널
- 상위 키워드: 복잡도 조절 하이퍼파라미터

KNN

- K = 하이퍼파라미터. K↑ 경계 단순(과소) / K↓ 경계 복잡(과대) 특강

나이브 베이즈: 베이즈 + 입력변수 독립 가정. 독립 아니면 성능↓. 출제 가능성↓, 가정만.

  • 장: 단순·빠름 / 단: 구형, 이상치 민감, 초기값, K 필요

DBSCAN (밀도)

지표 식 한 줄
MSE 평균 (y−ŷ)² 큰 오차에 민감

              예측 P    예측 N
실제 P         TP        FN
실제 N         FP        TN

T/F = 맞/틀림, P/N = 예측 방향.

지표 식 언제
정확도 Accuracy (TP+TN)/전체 불균형이면 왜곡
정밀도 Precision TP/(TP+FP) FP가 치명 (스팸, 무고)
재현율 Recall TP/(TP+FN) FN이 치명 (암, 사기 놓침)
특이도 Specificity TN/(TN+FP)
F1 2PR/(P+R) 정밀·재현 조화평균
F-β β>1 재현 중시

재현율 = 민감도 = TPR = Hit Rate

정밀 ↔ 재현 트레이드오프 (임계값)
