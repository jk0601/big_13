1. 회귀분석 — 가정 + ANOVA표

모수적. 가정 1순위 특강. 해석 문제 = “R 출력 읽기”가 아니라 아래.

가정 ☞ 선등정독: 선형성, 등분산, 정규성(잔차), 독립성
잔차 분석으로 확인. 위반 시:
- 선형성 위반 → 변환, 다항, 비선형
- 등분산 위반 → 가중회귀, 변환, 로버스트
- 독립성 위반(자기상관) → DW 통계, 시계열 모형
- 정규성 → 2과목 정규성 검정

ANOVA표로 묻는 것 특강

SST = SSR + SSE
R² = SSR/SST = 1 − SSE/SST
자유도: 회귀 p / 잔차 n−p−1 / 전체 n−1
MSR=SSR/p, MSE=SSE/(n−p−1), F=MSR/MSE
  • 모형 전체 유의성 = F (H0: 모든 β=0)
  • 개별 계수 유의성 = t
  • 표에서 R²를 계산할 수 있는가

다중공선성: VIF≥10, 변수 제거·PCA·Ridge
수정 R²: 변수 수 벌점, 다중회귀 비교용
AIC/BIC 작을수록, 상대 비교. “AIC로 계수 유의성 검정”(X)
전진/후진은 2과목 래퍼와 동일 → 패스 가능

5. SVM · KNN

SVM
- 선형·비선형 모두. 비선형 = 커널
- 상위 키워드: 복잡도 조절 하이퍼파라미터
- C(cost)↑ → 오차 엄격, 경계 복잡, 과적합 쪽
- 하드 마진: 오차 0 목표, 노이즈에 취약 / 소프트 마진: 슬랙으로 일부 허용
- 마진 최대 초평면, 서포트벡터 = 경계 최근접 점

KNN
- 분류·회귀 모두. Lazy. 이상값에 취약 → 실무는 RF를 더 씀
- K = 하이퍼파라미터. K↑ 경계 단순(과소) / K↓ 경계 복잡(과대) 특강
- 거리 기반 → 스케일링 필수

나이브 베이즈: 베이즈 + 입력변수 독립 가정. 독립 아니면 성능↓. 출제 가능성↓, 가정만.

6. 연관규칙 — 1문항, 계산 가중치↓ 특강

지지도 P(A∩B) / 신뢰도 P(B|A) / 향상도 P(A∩B)/(P(A)P(B))
향상도 >1 양의 관계, =1 독립, <1 음
신뢰도만 높다고 유용하지 않음 (B가 원래 많이 팔리면)

장단 꼭 (늘 출제)
- 장: 조건→결과 명확, 목적변수 불필요, 실무 이해 쉬움
- 단: 품목 증가 시 계산 폭발, 인과 아님, 희귀 중요규칙 놓칠 수 있음

7. 군집분석 — 3과목 전략 특강

비지도. 상위 개념 = 군집 수를 누가 정하는가 (지도학습의 과적합에 해당).

계층적 vs 비계층적(분할적)

계층적 비계층적(분할, 비계층)
관계 수직 (트리) 수평
군집 수 나중에 덴드로그램으로 보통 사전 지정(K-means)
그래프 덴드로그램만 계층에 있음. Y=군집 간 거리 없음
방향 병합(작은→큰) / 분할(큰→작은) 한 레벨

특강 100%: 덴드로그램에 수평선 그어 교차하는 수직선 수 = 군집 수.

병합 연결 5 (많이 출제): 단일(최단) · 완전(최장) · 평균 · 중심 · 와드(군집내 분산 증가 최소)
거리: 유클리드, 맨하튼, 마할라노비스(이상값·상관, 정의), 자카드(범주, 연속거리 아님)

계층 vs 비계층 장단 거의 매회
- 계층: 시각적, K 사전 불필요 / 대용량 느림, 한번 병합이면 되돌리기 어려움
- 비계층: 대용량 빠름 / K 지정, 초기값, 구형 가정(K-means)

K-means

  • 분석자가 K 지정. 자동 결정 아님
  • 순서: K → 초기 중심 → 할당 → 중심 갱신 → 반복
  • K 결정: 엘보(WCSS), 실루엣. (PCA의 주성분 수 결정과 같은 비지도 논리)
  • 장: 단순·빠름 / 단: 구형, 이상치 민감, 초기값, K 필요

DBSCAN (밀도)

  • K 지정 안 함 특강 포인트
  • 임의 모양, 노이즈를 이상치로. K-means가 구형에서 약할 때

SOM 자기조직화도

  • ANN 계열 비지도. 시험은 지도학습 ANN과 비교 + 구조
  • 구조: 입력층 + 경쟁층, 뉴런 전부 완전연결
  • 역전파 없음(승자독식)
