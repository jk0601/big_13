1-4. 차원축소 — 기준점은 항상 PCA 특강

PCA: 원변수를 보존하지 않음. 상관 높은 변동을 주성분(최대분산 축, 직교, 비지도) 으로.

vs PCA 차이 한 줄
요인분석 FA PCA=변동 큰 축 / FA=공통 잠재요인
SVD PCA는 정방(공분산) 분해 / SVD는 비정방도 가능 ★ 반복
LDA PCA=비지도·분산최대 / LDA=지도·클래스 분리 최대
래퍼 변수선택 원변수 선택(보존) / PCA는 변환(비보존)

기타: t-SNE·UMAP(시각화), MDS(거리보존), 오토인코더, ICA
주성분 개수: 누적기여율 70~90%, 스크리 엘보, 고유값≥1 — 3과도 약하게 겹침(가중치↓)

1-5. 파생변수 vs 요약변수

| 요약변수 | 수집 정보를 종합, 재활용 높음 | 1개월 총구매액 |
| 파생변수 | 의미 부여해 새로 만듦, 논리 타당성 | 구매등급, 최근1년 평균구매 ★ |

EDA(탐색, 기술통계) vs CDA(확증, 가설검정·추론)

2-1. 기초 통계량

중심: 산술 ≥ 기하 ≥ 조화 / 중앙값은 순서만 보므로 이상치에 강함 / 최빈은 범주형도
산포: 범위, 분산, SD, IQR, CV=SD/평균 (단위 다른 집단 비교)
왜도>0 오른쪽 꼬리: 최빈 < 중앙 < 평균 (“평균은 꼬리를 따라간다”) ★매회
첨도: 정규=3 (excess는 0)
왜도·첨도 = 연속형 전용

2-1b. 상관 특강 — 매회 1문항

상관 = 두 변수의 강도 + 방향. 다변량이지만 탐색에도 위치.

공분산 Cov 피어슨 r
범위 −∞ ~ +∞ −1~1
단위에 민감 표준화한 공분산
독립이면 반드시 0 구간척도↑, 선형

특강 포인트
- 독립 → Cov=0 (O) / Cov=0 → 독립 (X, 비선형 가능)
- 피어슨: 구간·비율, 선형, 이상치 민감
- 스피어만: 서열. 구간·비율을 순위화 가능. 비선형(단조)도 포착 ★ 전부 출제 포인트
- 상관 크기만으로 통계적 유의성 불가 → 가설검정 필요
- 켄달 τ도 순위 기반

2-2. 시각적 탐색

히스토그램: 계급(bin)이 좁으면 들쭉날쭉, 넓으면 패턴 소실 — 해석 문항
상자그림: 위 1-2절
고급(4과목과 중복, 정의만): 단계구분도, 카토그램, 조건플롯, 평행좌표
- 다변량 시각 해석(PCA 바이플롯 읽기 등)은 가중치↓

2-3. 비정형 탐색 특강 — 용어만, 깊이 금지

한때 3~4문항으로 과락 발생 → 이후 가중치↓. 실기 주대상도 아님.

전처리 용어만:
- 토큰화(Tokenizing)
- POS 태깅(품사)
- 스테밍(Stemming): 기계적 접사 제거
- 표제어 추출(Lemmatization): 사전 기반 원형

불용어, 정규화 정도까지. 임베딩·토픽모델로 확장하지 말 것.

3-2. 표본추출 4 · 척도 4 특강 100% — 틀리면 심각

척도: 명목 / 서열 / 등간(절대0 없음) / 비율(절대0)

3-3. 조건부 확률 · 베이즈

P(A|B)=P(A∩B)/P(B)
독립이면 P(A∩B)=P(A)P(B), P(A|B)=P(A) — 교집합 계산이 다름 특강
배반 ≠ 독립
베이즈: P(A|B)=P(B|A)P(A)/P(B) — 초기엔 많이, 최근 가중치↓. 유도 관계만.

3-4. 확률분포 — 정의 + 기댓값·분산 특강 (빅분기 특징)

ADSP는 특징 구분 / 빅분기는 E, V 수식까지

이산
| | 상황 | E | V |
|---|---|---|---|
| 베르누이 | 1회 성공실패 | p | p(1−p) |
| 이항 B(n,p) | n회 성공횟수 | np | np(1−p) |
| 기하 | 첫 성공까지 횟수 | 1/p | |
| 초기하 | 비복원 성공횟수 | | 시행 간 비독립 |
| 포아송 | 단위시간 발생횟수 | λ | λ |

연속: 정규 / t(꼬리 두꺼움, df↑→정규) / χ²(모분산, 적합도) / F(분산비, ANOVA)

기댓값 성질 ★: E(aX+b)=aE(X)+b, V(aX+b)=a²V(X)
독립이면 V(X±Y)=V(X)+V(Y) (빼도 더함)

CLT 100% (오답으로)
- 모집단이 정규일 필요 없음
- 표본평균의 분포 (표본분산의 분포 아님)
- n 충분히 크면 표본평균 ~ 정규 근사 → 모수적 검정 가능
- E(X̄)=μ, V(X̄)=σ²/n, SE=σ/√n

3-5. 추정

불편추정량: 한 번 구한 표본평균이 모평균과 같다는 뜻이 아님.
표본평균의 기댓값이 모평균과 같을 때 = 불편. 특강 (오답 고르기용으로 정의를 정확히)

좋은 추정량 ☞ 불효일충: 불편, 효율(분산 작을수록, “분산 0”은 함정), 일치, 충족
표본분산 n−1: 불편추정
MSE = Var + Bias²

구간추정
- 점추정은 오류 큼 → 구간 + 반드시 신뢰수준 명시
- 95%의 의미: 같은 방법으로 100번 중 95번 모수를 포함. 확률이 아님 (모수는 상수)
- 신뢰수준↑ → 구간 넓어짐 / 표본 n↑ → 구간 좁아짐
- n을 4배로 → 구간 폭은 약 1/2 (√n)
- z: 90% 1.645 / 95% 1.96 / 99% 2.576
- 모분산 알면 z, 모르면 t(df=n−1)
- 계산은 과거 회차 선까지. 확장 금지 특강

3-6. 가설검정 특강 · 실기 3유형과 동일

  • 검정 대상은 귀무가설. 반박 근거 있으면 기각, 없으면 기각하지 못함 ≠ 귀무가 참
  • H0: 같다·차이없다 / H1: 입증할 주장
  • 단측: 크다·작다·증가·감소 / 양측: 같지 않다
  • α = 1종 허용 = P(참인 H0 기각)
  • β = 2종 = P(거짓 H0 채택)
  • 검정력 = 1−β
  • p < α → H0 기각
H0 참 H0 거짓
기각 1종 α 검정력
미기각 OK 2종 β

모수적 검정의 가정 1호 = 정규성. 확인: Shapiro, K-S, Q-Q, Jarque-Bera, 히스토그램
- t: 단일 / 대응(같은 대상 전후) / 독립 두 집단
- 3집단↑ 평균 = ANOVA / 분산비교 = F / 범주 = χ²

정규성 방법이 1·2·3·4로 제시됨 → “상위 키워드는 모수검정 가정”으로 묶어라 특강
