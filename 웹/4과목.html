4과목. 빅데이터 결과 해석

특강 — 두 번째 전략 과목

타깃 13~14. 1과목과 한 묶음으로 회독. 축이 3개뿐이라 유형이 단순하다. 이 3축이 문항의 약 50%(10문항). 1. 회귀·분류 평가지표 (3~4문항) 2. 정보 시각화 (3문항) + 인포그래픽 (1) 3. 과적합 방지 + 교차검증 세분 + 최적화 회귀 진단(잔차 등)은 3과목 회귀를 했으면 패스. 하이퍼파라미터 그리드/랜덤/베이지안은 가중치↓, 정의만. 실기는 40초 오버 시 감점이라 튜닝을 거의 안 함.

모형 평가의 목적 = 일반화 가능성. 학습 데이터와 평가 데이터에서 같은 성능이 나올 때 일반화 가능.

1장. 분석 모형 평가

1-1. 회귀 평가지표 특강 정의 매칭

지표 식 한 줄
MSE 평균 (y−ŷ)² 큰 오차에 민감
RMSE √MSE y와 단위 같음
MAE 평균 |y−ŷ| 이상치에 MSE보다 강
MAPE 평균 |(y−ŷ)/y| ×100 % , y=0 주의
R² 1−SSE/SST 0~1, 상대 설명력

문항: 정의를 주고 이름 고르기 / 회귀 지표 vs 분류 지표 섞어 놓기.

1-2. 분류 평가지표 · 혼동행렬 특강 3~4문항

              예측 P    예측 N
실제 P         TP        FN
실제 N         FP        TN

T/F = 맞/틀림, P/N = 예측 방향.

지표 식 언제
정확도 Accuracy (TP+TN)/전체 불균형이면 왜곡
정밀도 Precision TP/(TP+FP) FP가 치명 (스팸, 무고)
재현율 Recall TP/(TP+FN) FN이 치명 (암, 사기 놓침)
특이도 Specificity TN/(TN+FP)
F1 2PR/(P+R) 정밀·재현 조화평균
F-β β>1 재현 중시

재현율 = 민감도 = TPR = Hit Rate
FPR = FP/(FP+TN) = 1−특이도
정밀 ↔ 재현 트레이드오프 (임계값)

ROC: x=FPR, y=TPR(재현). AUC 1에 가까울수록 우수 (0.5=무작위)
함정: AUC 0.5가 우수(X) / ROC로 혼동행렬 원숫자 직접 산출(X)

이익도표·리프트: 상위 등급 반응 배율

1-3. 군집 평가 (3과목 연계)

실루엣 (b−a)/max(a,b), −1~1, 응집+분리
엘보: WCSS가 완만해지는 K

1-4. 교차검증 세분 특강 100% — 여기가 주력

3과목은 분할 개념, 4과목은 K-fold를 쪼갠다.

방법 한 줄
Holdout 한 번 분할
K-fold K개 폴드, K번 돌아가며 검증
층화 Stratified K-fold 각 폴드에 타깃 비율 유지 (불균형 처리와 다름!)
LOOCV K=n, 1개만 검증. 계산 큼, 편향 작음
LPOCV P개를 검증으로 남김 (Leave-P-Out)
몬테카를로 CV 무작위 분할을 여러 번 (ShuffleSplit)
부트스트랩 복원추출로 표본 재구성. 단순 랜덤 복원 특강

층화 K-fold ≠ 2과목 불균형 오버/언더 (비율을 바꿈)

1-5. 과적합 방지 4 + 배치정규화 함정 특강

커리큘럼에 명시된 4가지 (개별·묶음 모두 출제):
1. 데이터 증강·증가
2. 모형 단순화 (층·노드·나무깊이↓)
3. 규제 Regularization (L1/L2, 가중치 감소) ← 2과목 임베디드와 교집합
4. 드롭아웃 (학습 시 뉴런 랜덤 비활성, 추론 시 전부 사용)

보조: 조기종료(검증오차 반등 시 중단), 교차검증
에포크를 늘리는 것 = 과적합 유발 (방지책 아님)

기출 함정 — 배치정규화

주목적 = 학습 안정화(내부 공변량 이동 완화). 정규화 효과로 부수적으로 과적합도 줄어들 수 있다. “과적합 방지 4가지” 목록에는 없어도 정답이 된 문항이 있다.

규제 복습: Ridge=L2 축소만 / Lasso=L1 계수0 변수선택 / Elastic=혼합

1-6. 파라미터 vs 하이퍼파라미터 특강

| 파라미터 | 모델이 학습으로 내부 결정 | 가중치 w, bias, 회귀계수 |
| 하이퍼파라미터 | 학습 전에 분석자가 설정 | 학습률, 층수, K, C, 드롭아웃율, 에포크, 배치 |

1-7. 경사하강법 · 옵티마이저 특강 변별력 (난이도 줄 곳)

W ← W − α ∂Loss/∂W
- 학습률 α 큼: 발산·진동 / 작음: 느림
- 전체 데이터라 느림 → 확률적 등장

데이터 특징
Batch GD 전체 안정, 느림, 메모리
Mini-batch 쪼갠 묶음 실무 표준
SGD 한 개(또는 랜덤 하나) 빠름, 진동, 지역해 탈출에 유리

SGD 개량 — 기울기 기준 vs 학습률 기준 특강 최소 암기
| 모멘텀 | 이전 기울기 관성 (기울기 쪽) |
| AdaGrad | 파라미터별 학습률, 누적제곱 → 학습률이 점점 감소 (학습률 쪽) |
| RMSProp | 기울기 제곱의 지수이동평균으로 학습률 |
| Adam | 모멘텀 + RMSProp |

특강: 적어도 모멘텀 · AdaGrad · Adam. 그 아래도 출제 가능하나 우선 셋.
비볼록에서 항상 전역 최소(X).

하이퍼 탐색 (가중치↓): 그리드=전수·느림 / 랜덤=임의 / 베이지안=과거 경험으로 유망 영역.

이 파라미터들로 복잡도 vs 성능 안정성을 조절.

정규성 검정은 평가 파트에도: Shapiro, K-S, Q-Q (t-test는 정규성 검정 아님)

2장. 분석 결과 시각화 — 3문항 + 인포 1 특강

정보시각화 축: 시간 · 분포 · 공간 · 관계 · 비교

유형 목적 대표 함정
시간 변화, x=시간 선, 영역, 계단
분포 모양·구성 히스토그램, 박스, 파이, 바이올린, 트리맵 히스토그램을 관계에 넣기

히트맵 vs 트리맵 특강 꼭
| 히트맵 | 행렬 칸의 색으로 값. 상관·혼동행렬 |
| 트리맵 | 면적(+색) 으로 계층 비율. 음수 불가 |

- 로그 스케일: 지수적 증가

시험 직전 체크리스트 (4과목)

  1. 평가 목적 = 일반화 (train≈test 성능)
  2. 회귀: MSE RMSE MAE MAPE R² 정의 매칭
  3. 정밀도=TP/(TP+FP), 재현=TP/(TP+FN)=민감도=TPR, F1=조화평균
  4. 불균형 → 정확도 믿지 말 것 / FN치명=재현 / FP치명=정밀
  5. ROC: x=FPR y=TPR, AUC↑좋음
  6. K-fold 세분: 층화=비율유지, LOOCV, LPOCV, 몬테카를로, 부트스트랩=복원
  7. 과적합 방지 4: 데이터·단순화·규제·드롭아웃 / 에포크↑는 유발
  8. 배치정규화=안정화가 본업, 과적합은 부수
  9. 규제: L1 선택 / L2 축소 — 2과목 임베디드와 같음
  10. 파라미터=학습, 하이퍼=분석자 사전 설정
  11. GD: Batch 전체 / Mini / SGD 샘플 / 학습률 크기
  12. 모멘텀=관성, AdaGrad=학습률 감소, Adam=모멘텀+RMSProp
  13. 시각화 3문항: 히스토그램=분포, 히트맵≠트리맵, 카토그램=면적왜곡
