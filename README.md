# 13회 빅데이터분석기사 필기 쪽집게

2026-08-25 김계철 라이브 특강 + 기존 4과목 노트 + 기출응용 70문항을 한 세트로 압축한 회독본입니다.

특강 권고: **A4 50장 안팎으로 줄여 1·2·3·4를 같은 주에 여러 번 본다.**  
1·4과목을 전략(13~14문항), 2·3을 방어(11~12)로 둔다. 합격은 48/80, 과목당 8 이상.

## 파일

| 파일 | 용도 |
|---|---|
| `index.md` | 옵시디언 목차(MOC) |
| `00_합격전략_쪽집게.md` | 전략·교집합·이번 회 예상 |
| `1과목_분석기획_쪽집게.md` ~ `4과목_결과해석_쪽집게.md` | 과목별 쪽집게 + OX |
| `웹/index.html` | 브라우저 학습 홈 (서버 불필요) |
| `웹/합본.html` | 네 과목 + 전략 합본, 인쇄→PDF |

## 옵시디언

`정리노트/13회_쪽집게` 폴더를 볼트에 추가하거나, 이 폴더를 볼트로 연다.  
위키링크 `[[1과목_분석기획_쪽집게]]` 로 과목이 연결된다.

## 웹

`웹/index.html` 을 Chrome/Edge로 연다. 과목 하단 퀴즈는 눌러서 답을 본다.  
합본은 `Ctrl+P` 로 인쇄·PDF 저장.

HTML을 다시 만들 때:

```
python 웹\build_web.py
```

(상위 `정리노트` 상세 노트·기출집은 깊이 볼 때만 사용.)
